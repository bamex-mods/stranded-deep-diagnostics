# Stranded Deep Diagnostics v1.0.0-rc1

First public release candidate of the Stranded Deep runtime diagnostics and targeted tracing toolkit for BepInEx mod development.

The RC includes split-screen-aware object/camera/input inspection, physics and UI inspection, saveable/storage/inventory/world/construction inspectors, snapshot/diff/report export, targeted opt-in Harmony tracing, AUDIO and RAFT incident tooling, capability degradation, and optional BamEx adapters.

The tool is inspection-first and does not intentionally modify gameplay, save data, Rigidbody state, placement validity, attachment state, or collision-ignore state.

License: MIT.

Requires BepInEx 5.

This is a pre-release candidate. It should not be added to the public stable catalog until the RC verification path is complete and final `v1.0.0` is promoted.

- English and Russian usage guides are included in source and in the install payload.
